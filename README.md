## ディレクトリ構成

検証ごとに `YYYY-MM-DD-{条件}` の形式でディレクトリを作成し、その配下に各回の `README.md` / `images` / `models` を配置する

```
YYYY-MM-DD-{条件}/
├── README.md   検証内容・結果まとめ
├── images/     検証に使用・生成した画像
└── models/     ダウンロードした3Dモデルデータ
```

例: 有料版での検証を行う場合は `2026-09-07-pro` のようなディレクトリを追加する
